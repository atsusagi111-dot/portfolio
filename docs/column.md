# コラム記事の追加手順

コラムは `content/column/` に Markdown ファイル（`.md`）を置くだけで追加できます。
一覧・カテゴリ別一覧・記事ページ・関連記事・sitemap.xml・RSS は、ビルド時に自動で更新されます。

## 1. ファイルを作る

`content/column/` に `記事のURL.md` という名前でファイルを作ります。

- ファイル名がそのまま URL になります（例：`ai-chatbot-basics.md` → `/column/ai-chatbot-basics/`）
- 使えるのは **半角の英小文字・数字・ハイフン** だけです（日本語・大文字・スペース・アンダースコアは不可）
- `page.md` と `category.md` は使えません（一覧ページの URL と重なるため）
- 公開後にファイル名を変えると URL が変わり、検索エンジンの評価がリセットされます。最初に決めたら変えないでください

既存の `homepage-order-checklist.md` をコピーして書き換えるのが簡単です。

## 2. 冒頭の設定（frontmatter）を書く

ファイルの先頭に、`---` で囲んで次の項目を書きます。

```md
---
title: "記事のタイトル"
description: "記事の要約。検索結果や一覧に表示されます。"
date: 2026-10-01
updated: 2026-10-15
category: "AI活用"
tags: ["AIチャットボット", "問い合わせ対応"]
thumbnail: "/images/column/ai-chatbot-basics.webp"
---
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `title` | ○ | 記事タイトル（ページの h1 になります）。32字前後までが目安 |
| `description` | ○ | 要約。80〜120字が目安 |
| `date` | ○ | 公開日。`YYYY-MM-DD` 形式 |
| `updated` |  | 更新日。内容を直したときに書き換える |
| `category` | ○ | 「ホームページ制作」「AI活用」「業務効率化」「お知らせ」のいずれか（一字一句同じに） |
| `tags` |  | タグ。関連記事の判定に使われます |
| `thumbnail` |  | サムネイル画像のパス。空（`""`）にするとグレーの仮画像になります |
| `draft` |  | `draft: true` と書くと、その記事は公開されません（下書き用） |

## 3. 本文を書く

frontmatter の下に Markdown で本文を書きます。

- **見出しは `## `（h2）から始めます。** `# `（h1）は記事タイトルに使うため、本文で使うとビルドがエラーになります
- `## ` と `### ` の見出しから、目次が自動で作られます。見出しの階層は飛ばさないでください（`## ` の次にいきなり `#### ` としない）
- 使える書式：段落、箇条書き（`- `）、番号リスト（`1. `）、**太字**、リンク、引用（`> `）、表、画像

```md
## 大見出し

本文の段落です。**強調したい語句**は太字にできます。

### 小見出し

- 箇条書き
- 箇条書き

[サービス内容はこちら](/services/)
```

### 守ること（CLAUDE.md のルール）

- 実績・数値・お客様の声・事例は、**事実だけ**を書く。創作しない
- 他サイトの文章・画像を流用しない

## 4. サムネイル画像を用意する（任意）

1. **1200×630px**（横長）の画像を用意する（JPG または PNG）
2. `assets-src/column/記事のURL.png`（または `.jpg`）として保存する
3. frontmatter に `thumbnail: "/images/column/記事のURL.webp"` と書く（拡張子は `.webp` になります）

ビルド時に自動で軽い形式（WebP）へ変換され、`public/images/column/` に出力されます。
この画像は SNS でシェアされたときの画像（OGP）にも使われます。

本文中に画像を入れる場合も同じ場所に置き、`![画像の説明](/images/column/ファイル名.webp)` と書きます。

## 5. 確認して公開する

```bash
npm run dev      # http://localhost:3000/column/ で表示を確認
npm run build    # エラーが出ないことを確認（out/ が生成される）
```

問題なければ、`docs/deploy.md` の手順で `out/` をアップロードします。

### よくあるビルドエラー

| メッセージ | 対処 |
|---|---|
| `frontmatter に ◯◯ がありません` | 必須項目（title / description / date / category）を追加する |
| `category「◯◯」は未登録です` | カテゴリ名を登録済みのものと一字一句同じにする |
| `date は YYYY-MM-DD 形式で…` | `2026-10-01` の形式にする（`2026/10/1` は不可） |
| `記事本文に「# 見出し」（h1）は使えません` | 本文の `# ` を `## ` に直す |
| `ファイル名…は半角英小文字・数字・ハイフンだけ` | ファイル名を直す |

## 補足

- **カテゴリの追加・変更**：`data/column.ts` の `columnCategories` を編集します（`slug` は URL に使う半角英字）
- **1ページあたりの記事数**：`data/column.ts` の `perPage`（初期値 9）。超えると自動でページ送りが付きます
- **記事を削除する**：`.md` ファイルを削除します。ただし静的エクスポートの仕様上、**記事は最低1本**必要です（0本だとビルドエラーになります）
- **サンプル記事**：`homepage-order-checklist.md` は表示確認用のサンプルです。公開前に内容を確認し、書き換えるか、別の記事を追加したうえで削除してください
