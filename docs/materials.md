# 素材一覧（ご用意いただくもの）

サイト内の `【要素材：〇〇】` `【後で指定】` に対応する一覧です。
素材を受け取ったら「提供状況」を **済** に更新し、「反映先」のファイルを修正します。

- 画像は `assets-src/` 配下の同名ファイルを差し替えるだけで反映されます（拡張子は jpg / png どちらでも可。ビルド時に自動で軽量化され、`public/images/` に出力されます）。表示枠の比率は固定で、はみ出す部分は自動で切り抜かれます
- 文章は `data/` 配下のファイルを書き換えるだけで反映されます
- 形式：写真は JPG / PNG（長辺 1600px 以上あれば十分）。文章はメール・チャット・Word など何でも構いません
